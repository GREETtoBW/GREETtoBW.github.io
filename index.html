GREETtoBW · open pipeline

Argonne's GREET model, unlocked as a Brightway-ready inventory.

GREET's life-cycle data for fuels, vehicles, and materials lives in a two-thousand-tab Excel workbook. GREETtoBW traces every formula back to its source and rebuilds it as linked EcoSpold2 datasets, so it opens directly in Brightway, with each number still traceable to the cell it came from.

Common questions

FAQ

Is this an official Argonne or GREET release? +

No. GREETtoBW is an independent research pipeline built on top of the publicly distributed GREET workbooks. It is not affiliated with or endorsed by Argonne National Laboratory.

Do I need Excel to use the output? +

No. The dependency-tracing stage needs Excel once, to walk the workbook's formulas. Everything downstream, building and using the EcoSpold datasets, runs without it.

Can I trust a number without re-deriving it myself? +

Every dataset carries the GREET anchor cell it was traced from. You can always walk back to the source formula in the workbook rather than take the output on faith.

Can I get the code? +

The repository isn't public yet. Datasets built from the pipeline are shared on request while coverage is still growing, ask above.

How do I get in touch? +

Use the form above, or write directly to fzhao@purdue.edu.

Why this exists

GREETtoBW is a path from the workbook into LCA software.

01

Formulas, not a database

Every value in the public GREET workbook is a live Excel formula chained across dozens of sheets, and there's no exported database, only the spreadsheet itself.

02

A bridge from Excel

Brightway reads EcoSpold or ecoinvent-style exchange data. GREETtoBW builds that bridge from the Excel workbook.

03

Provenance gets lost by hand

Manual transcription drops the link back to the source cell and the scenario switch behind it, so a reviewer can't check a number against the workbook it came from.
